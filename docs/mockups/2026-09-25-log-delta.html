#75 · how much sooner than last life

Every log line already starts with the run clock, so "the hull was finished at 2:15" is on screen today. What #75 adds is the comparison with the last life that finished the same row. Only one-time rows get it (the hull, the net, the satchel, the pirates, the sails), and a row finished for the first time ever gets nothing.
